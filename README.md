# საგამოცდო პროექტი / Final Certification Project

ეს რეპოზიტორიუმი აერთიანებს Front-end დეველოპმენტის კურსის განმავლობაში მიღებულ ყველა პრაქტიკულ ცოდნას. პროექტი აგებულია ნულიდან და ეტაპობრივად მიყვება იმ მთავარ ნაბიჯებს, რომლებიც თანამედროვე ვებ-გვერდების შესაქმნელადაა საჭირო — სუფთა მარკირებიდან დაწყებული, რესპონსივ დიზაინითა და ასინქრონული JavaScript ლოგიკით დასრულებული.

This repository represents the final milestone of the web development course. It is a step-by-step practical implementation of building modern, responsive, and interactive web applications from scratch.

---

## 📂 პროექტის სტრუქტურა / Project Structure

კოდის წესრიგისა და სისუფთავისთვის, მთელი საგამოცდო მასალა დაყოფილია 3 მთავარ მიმართულებად:

### 1. 📁 `Markup and style`
* **რაზეა:** ვებ-გვერდის სემანტიკური ჩონჩხის აწყობა W3C სტანდარტების დაცვით.
* **შიგთავსი:** HTML5 სტრუქტურა, მულტიმედია (სურათები და ვიდეო კონტროლერებით), მონაცემთა ცხრილები და ფუნქციური სარეგისტრაციო ფორმები სხვადასხვა ატრიბუტით.

### 2. 📁 `tailwind and scss`
* **რაზეა:** თანამედროვე სტილების მართვა და ვიზუალური ეფექტები ორი სხვადასხვა მეთოდით.
* **Sass (SCSS):** მოდულური არქიტექტურა, Nesting, ფონის გრადიენტები, 2D ტრანსფორმაცია და `@keyframes` ანიმაცია (ტექსტის დატრიალება 260 გრადუსით).
* **Tailwind CSS:** ადაპტური და მოქნილი ინტერფეისის სწრაფი დიზაინი (Responsive) სხვადასხვა ეკრანის პრეფიქსების გამოყენებით.

### 3. 📁 `javascript`
* **რაზეა:** ვებ-გვერდის გაცოცხლება, მომხმარებლის ივენთებზე რეაგირება და მონაცემებთან მუშაობა.
* **შიგთავსი:** საბაზისო ლოგიკა და ციკლები, მასივების კომპლექსური ფილტრაცია და სორტირება, LocalStorage, ტაიმერები, DOM მანიპულაციები და ასინქრონული Fetch API მოთხოვნები (GET/POST) გარე სერვერებთან დასაკავშირებლად.
